# 发布隐私边界

仓库是从允许公开的文件逐个复制、整理建立的独立源码目录，没有导入原始设备案例目录或聊天记录，也没有复制原工作目录的 Git 历史。

不发布以下内容：

- USB / ADB 序列号、硬件唯一标识、设备闪存 ID、私有 GPT GUID。
- Mac 用户名、本机绝对目录、主机名、个人网络或账号信息。
- 密码、API key、访问 token、环境文件、签名私钥与 keystore。
- userdata、原始整机备份、备份整盘哈希、设备私有日志与个人笔记 / 文档 / 图书截图。
- 原厂固件、原始 / 修补 boot 镜像、厂商 APK、反编译的厂商源码。

设备信息使用运行时环境变量，示例序列号为占位符。实际日志、备份及生成镜像只应留在自己的私有 case 目录。`work/`、`dist/`、镜像、APK、密钥与日志均在 `.gitignore` 中排除。

固件版本、公开更新 URL、原厂文件哈希、通用型号指纹和脱敏验证结论用于研究复现，可以公开。第三方源码保留其原有公开作者、版权和许可证信息，它们不是设备所有者的私人信息。

发布前按明确文件清单检查文本与发行包，并检查 Git 提交作者使用 GitHub noreply 身份。GitHub 账号本身及其已有公开资料仍由账号的隐私设置决定；本项目不会额外发布本地真实姓名或邮箱。

后续提交 issue 时也请勿附上自己的完整备份、原始日志、序列号或私人截图。
